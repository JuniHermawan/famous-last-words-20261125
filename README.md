The funniest one-line tombstone epitaph: a dying speaker cut off just before revealing the meaning of life. The epitaph is "I finally found the meaning of life. It's—" — the stone stops mid-word, so the absence of the answer is the punchline.

## Run it

```sh
python3 main.py
```

This writes the epitaph to `/output/entry.txt` (or `$ENTRY_OUTPUT`).
